Quick Guide

About

This is an unofficial preset editor for the Teenage Engineering EP–2350 Ting microphone. It allows you to create, edit, and export custom effect chains and modulation settings without using the official app.

Modes

Emulation: Tweak and preview presets using your browser's audio.

Live: Connect your EP-2350 via USB to edit presets directly on the device. Must route audio through an audio interface and use a DAW to expose the channel.

Building Presets

Click + Add Effect to add effects to your chain. Drag to reorder. Each preset can have up to 16 effects.

Some effects (Delay, Reverb, Harmony, SSB) can only be used once per preset.

Modulation

Handle: Map the device's handle to any effect parameter.

Shake: Map the accelerometer (shaking) to a parameter.

LFO: Add automatic oscillation to any parameter.

Trigger: Set which effect row responds to sample playback.

Saving

In Live mode, click Save to Device to write your changes to the EP-2350.

Use Export JSON to download your pack as a config file.

Live Mode Limitations

The device communicates via a MicroPython REPL interface, which has inherent limitations:

  • Parameter tweaking is sent to the device when you release the slider, not during dragging.
  • Adding, removing, or reordering effects is disabled in Live mode. Use Emulation mode to design presets, then export/import.
  • Preset switching syncs between app and hardware button.
  • The SSB effect may produce a tone at certain frequencies (device behavior).

Recommended workflow: Design presets in Emulation mode, then connect to transfer them to the device.

Disclaimer

If you happen to break the json file for some reason and the device freezes, don't panic. Simply connect to a computer and hold the green + white buttons during startup to access and fix the file. For any other questions, visit the official guide.
